# jlblancoupm.github.io

Personal academic website for José Luis Blanco Murillo, served with GitHub Pages and Jekyll.

## Structure

- `index.html` — landing page
- `about.html` — short personal/professional profile
- `research.html` — research directions, projects and funding
- `supervision.html` — supervision, open topics and prospective-student contact form
- `teaching.html` — selected teaching activity
- `publications.html` — journals and conference contributions with research taxonomy
- `_data/` — structured site content

Deployment is performed only from `main` through `.github/workflows/pages.yml`.
