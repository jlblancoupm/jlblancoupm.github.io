# Security and privacy

This public GitHub Pages repository contains only information intended for publication.

- No personal recipient email address is stored in the repository.
- No contact form or incomplete contact mechanism is included in the stable baseline.
- No third-party analytics or form-processing service is loaded.
- Private canonical data, operational history and future automation belong in the private `profile-data` repository.
- Public exports should continue to follow a whitelist/sanitizing model.
